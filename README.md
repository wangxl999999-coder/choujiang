# 🎯 抽奖助手 - 微信小程序

一款功能丰富、界面美观的抽奖助手类微信小程序，支持多种抽奖样式，满足年会、公众号、小红书等抽奖需求。

## ✨ 功能特性

### 📱 小程序端功能

#### 🏠 首页模块
- **Banner轮播**：展示活动公告和推广
- **快捷入口**：我的抽奖、创建抽奖、中奖记录、客服入口
- **活动列表**：展示所有公开抽奖活动，按时间倒序排列
- **活动卡片**：包含标题、封面、奖品名称、参与人数、剩余时间、抽奖类型标签
- **筛选功能**：按类型筛选（大转盘/九宫格/随机滚动/一键开奖）
- **状态筛选**：全部/进行中/即将开始/已结束
- **搜索功能**：按活动标题或奖品名称搜索

#### 🎡 抽奖展示形式
- **大转盘**：经典转盘抽奖，支持自定义奖项和概率
- **九宫格**：3x3网格抽奖，中间为开始按钮
- **随机滚动**：老虎机式滚动抽奖
- **一键开奖**：点击即可立即开奖
- **背景音乐**：后台可配置
- **抽奖音效**：增强互动体验
- **中奖弹窗**：美观的中奖提示

#### 📝 抽奖创建模块
- **三步表单设计**：
  1. 基本信息（标题、封面、抽奖类型、简介）
  2. 奖品设置（支持多奖品、数量、概率、图标）
  3. 规则设置（参与方式、次数限制、时间范围、公开/私密）
- **参与方式**：
  - 公开参与
  - 关注公众号后参与
  - 小红书关注后参与
- **发布预览**：发布前可预览活动效果

#### 👤 用户中心
- **用户信息**：头像、昵称、手机号
- **数据统计**：参与抽奖数、中奖次数、邀请好友数
- **我参与的**：查看参与的所有抽奖活动
- **我的中奖**：查看中奖记录和兑奖码
- **收货地址**：管理收货地址
- **邀请好友**：社交裂变，邀请得抽奖次数
- **联系客服**：多种联系方式

## 🚀 快速开始

### 小程序端

1. 下载并安装微信开发者工具
2. 导入项目：选择 `miniprogram` 目录
3. 配置小程序 AppID
4. 点击编译运行

### 管理后台

1. 直接在浏览器中打开 `admin/index.html`
2. 默认账号：`admin` / `admin123`
3. 体验完整后台功能

## 🎨 技术栈

### 小程序端
- 微信小程序原生框架
- WXML + WXSS + JavaScript

- 原生 HTML5 + CSS3 + JavaScript

## 🔧 功能配置

### 抽奖类型配置
在 `miniprogram/pages/create/create.js` 中配置：
```javascript
lotteryTypes: [
  { name: '大转盘', value: 'wheel', icon: '🎡' },
  { name: '九宫格', value: 'grid', icon: '🔲' },
  { name: '随机滚动', value: 'scroll', icon: '🎲' },
  { name: '一键开奖', value: 'oneclick', icon: '🎯' }
]
```

### 参与方式配置
```javascript
joinTypes: [
  { name: '公开参与', value: 'public', icon: '🌐', desc: '所有人可直接参与' },
  { name: '关注公众号', value: 'follow', icon: '📱', desc: '关注公众号后参与' },
  { name: '小红书关注', value: 'xiaohongshu', icon: '📕', desc: '关注小红书账号后参与' }
]
```
